# tex コマンドの仕様

## 概要

`/tex` コマンドは、TeX(LaTeX) の数式文字列を受け取り、その数式を描画した PNG 画像を返信する。
数式を Discord 上で共有したいときに使う。

## 使い方

```
/tex formula:<TeX 数式>
```

- `formula`: 画像にしたい TeX 数式（必須、1〜500 文字）。
  - ディスプレイ数式として描画されるため、`$` などの区切り文字は不要。
  - 例: `E = mc^2`、`\frac{-b \pm \sqrt{b^2-4ac}}{2a}`

サーバー内・DM のどちらでも実行できる。

## 処理の流れ

1. 入力された数式を MathJax(`mathjax-full`)で SVG に変換する。
2. SVG のルート要素の大きさを `ex` 単位から `px` 単位に書き換える（描画ライブラリ非依存で大きさを安定させるため）。
3. `sharp` で SVG を PNG に変換する。このとき以下を行う。
   - 透過部分を白で塗りつぶす（Discord のダーク/ライト両テーマで視認できるようにするため）。
   - 数式の周囲に余白を付ける。
4. 生成した PNG 画像を添付ファイルとして返信する。画像はディスクには保存せず、メモリ上で処理する。

## エラー時の挙動

- TeX の構文が不正な場合は、画像の代わりにエラー内容（例: `Missing argument for \frac`）をメッセージで返す。
- それ以外の想定外のエラーが発生した場合は、共通のエラーハンドラが管理者への問い合わせを促すメッセージを返す。

## 制限・安全対策

- 入力は最大 500 文字（Discord 側で上限を強制）。
- 出力画像は最大辺 4096px に収まるよう、縦横比を保ったまま縮小する。
