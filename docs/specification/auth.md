# 認証の仕様

## 前提

- 入室希望者は `/register` で ITSCore（室員名簿）に登録されることで室員資格を得る。
- Discord は主要な連絡手段だが参加は任意。参加しただけではチャンネルを閲覧できず、認証が必要。

## 認証フロー

1. 管理者が `/register` で入室希望者を ITSCore に登録する
2. 入室希望者が招待 URL から Discord サーバーに参加する（Bot が「メール未認証」ロールを自動付与）
3. 入室希望者が `/auth` を実行し、静大メールアドレス（`@shizuoka.ac.jp`）を入力する
4. 届いた認証メールのリンクをクリックする（届くまで時間がかかることがある）
5. もう一度 `/auth` で同じメールアドレスを入力すると認証完了

認証完了時に Bot が自動で行うこと:
- 「メール未認証」→「認証済み」にロールを切り替え
- 所属に応じた学科ロールを付与
- ニックネームを ITSCore の登録名に変更

## ロール

ロールは Bot 起動時に存在しなければ自動作成される。

| ロール | 意味 |
|---|---|
| メール未認証 | 参加直後。認証が済んでいない |
| 認証済み | メール認証完了済み |
| 室員情報未確認 | ITSCore に情報はあるが所属が未確定 |
| 情報科学科 / 行動情報学科 / 情報社会学科 / 工学部 / 大学院 / その他 | 所属（アクティブメンバーのみ） |
| bot接頭辞旧室員 | 卒業生など |
| bot接頭辞管理者 | 管理コマンドを使用できる管理者 |
